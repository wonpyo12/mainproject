# 세션 기반 자동 등록 계획서 (시작 시 등록 → 종료 시 삭제)

작성일: 2026-06-16

## 목표

지금은 등록을 **수동으로** 따로 실행해야 한다 (`robocart.sh register` → 끝나면 `track`).
이를 바꿔서:

- **시작할 때 자동으로 등록** (정면/뒤돌기 촬영) → 곧바로 추적 시작
- **종료하면 등록 데이터 자동 삭제** → 다음 시작 때 새 사용자로 다시 등록

즉, "한 번 켜는 동안만 유효한 일회용 등록". 스마트카트가 손님마다 새로 따라가는 시나리오.

## 현재 구조

| 노드 | 동작 |
|---|---|
| `register_node.py` | 따로 실행 → 촬영 → `data/smart_cart_profile.json` 저장 후 종료 |
| `tracker_node.py` | 기존 프로필 로드 → 추적 |

→ 등록과 추적이 분리돼 있고, 프로필이 디스크에 영구 저장됨.

## 바꿀 구조

```
[시작]
  └ tracker 노드 실행
       ├ 프로필 있나?
       │   ├ 없음 → 자동 등록 단계 (정면→뒤돌기 촬영, 브라우저에 안내)
       │   └ 등록 완료 → 프로필 메모리 로드
       └ 추적 시작 (/image/annotated, /robocart/servo, /robocart/cmd_vel)
[종료] (Ctrl+C / stop)
  └ finally·시그널 핸들러 → 프로필 + 샘플 이미지 삭제
```

## 설계 항목

### A. 자동 등록 (시작 시)
- [ ] tracker 시작 시 프로필이 없으면 `register_user()` 를 먼저 호출.
- [ ] 등록 UI(카운트다운)는 기존처럼 `/image/annotated` 로 브라우저에 표시 (같은 노드라 토픽 공유).
- [ ] 등록 성공 → 바로 `run_tracking()` 으로 전환 (재실행/모델 재로딩 없음 — 모델은 이미 메모리에).
- [ ] 등록 실패(사람 못 찾고 타임아웃) → 재시도 또는 안내 후 종료.

### B. 자동 삭제 (종료 시)
- [ ] 종료 경로 3가지 모두 처리:
  - 정상 종료 / Ctrl+C → `finally` 블록에서 삭제
  - `SIGTERM`(스크립트 stop) → `signal` 핸들러 등록해 삭제
  - 강제 `kill -9` → 핸들러 안 돎 → **시작 시에도 기존 프로필 삭제**(부팅=초기화)로 보강
- [ ] 삭제 대상: `data/smart_cart_profile.json`, `data/samples/front`, `data/samples/back`.

### C. 구현 방식 (택1)
| 방식 | 내용 | 장단점 |
|---|---|---|
| **방식1: 통합 노드 (권장)** | `tracker_node` 에 등록 단계 통합. 한 프로세스가 등록→추적→정리 | UX 깔끔(한 번 실행), 모델 1회 로딩 |
| 방식2: 런처 오케스트레이션 | `robocart.sh session` 이 register→track 순차 실행, `trap` 으로 정리 | 코드 변경 적음, 모델 2회 로딩(느림) |

→ **방식1 권장**: 모델(YOLO/Pose/ReID)을 한 번만 로딩하고 등록↔추적을 한 노드에서 전환.

### D. 휘발성 보강 (선택)
- [ ] 프로필을 `/tmp` (tmpfs, 재부팅 시 소멸) 또는 RAM 디스크에 저장 → 강제종료/정전에도 안 남음.
- [ ] 또는 시작 시 무조건 기존 프로필 삭제(`--reset` 기본 동작화).

## 사용 흐름 (완성 후)

```bash
# 시작 — 이 한 줄이면 등록부터 추적까지
bash robocart.sh session     # (또는 track 이 자동 등록 포함)
#   → 브라우저 localhost:8090 에 "정면을 바라보세요" 카운트다운
#   → 뒤돌기 촬영 → 자동으로 추적 시작
# 종료 — Ctrl+C 또는
bash robocart.sh stop
#   → 프로필·샘플 자동 삭제 (다음 시작 때 새 등록)
```

## 구현 순서

1. `tracker_node.py` 에 "프로필 없으면 등록 먼저" 로직 추가 (방식1).
2. 시작 시 기존 프로필 삭제(휘발성) 옵션 추가.
3. 종료 정리: `finally` + `signal(SIGTERM)` 핸들러로 프로필·샘플 삭제.
4. `robocart.sh` 에 `session` 명령(또는 `track` 에 자동등록 통합).
5. 검증: 시작→등록→추적→종료→파일 삭제 확인. 강제종료 후 재시작 시 재등록 확인.

## 엣지 케이스 / 주의

- **등록 중 종료**: 부분 저장된 프로필/이미지도 정리 대상에 포함.
- **여러 사람**: 등록은 화면 중앙 1명 기준 (기존 로직 유지).
- **방향 검증**: 이미 적용됨(정면=front, 뒤=front 아님) — 그대로 활용.
- **삭제 안전성**: 삭제 경로를 `data/` 하위로 한정(상위 경로 삭제 방지).
